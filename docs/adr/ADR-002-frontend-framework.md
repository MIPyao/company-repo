# ADR-002: 前端框架选型

日期: 2026-05-09
状态: 已采纳
作者: CTO (a83dcf07-81be-46b5-863d-e6b31207a2b2)

## 上下文

MIPYAO需要选择前端框架来构建Web应用。作为zero person company，我们需要：
- 快速开发MVP（最小可行产品）
- 良好的开发体验和学习曲线
- 丰富的生态系统和社区支持
- 对AI辅助开发友好（有充足训练数据）
- 适合国内团队（中文文档完善）

候选方案：
1. **React** - 生态最大，但JSX与Vue模板语法差异大
2. **Vue 3** - 渐进式，中文文档优秀，国内生态成熟
3. **Svelte** - 编译型框架，代码简洁，但生态较小
4. **Angular** - 完整框架，但学习曲线陡峭

## 决策

选择 **Vue 3** 作为前端主力框架。

### 技术选型细节

| 项目 | 选择 | 理由 |
|------|------|------|
| 框架 | Vue 3 | 渐进式，Composition API灵活，中文文档完善 |
| 语法风格 | `<script setup>` + Composition API | 更简洁，逻辑复用更方便 |
| 构建工具 | Vite | 很速热更新，现代构建工具 |
| 状态管理 | Pinia | Vue 3官方推荐，TypeScript支持好 |
| 路由 | Vue Router 4 | Vue 3官方路由，无缝集成 |
| UI组件库 | Element Plus | 企业级组件库，文档完善 |
| 样式方案 | Tailwind CSS + SCSS | 实用优先 + 传统预处理器的结合 |
| 类型检查 | TypeScript | 类型安全，AI辅助开发友好 |

### 为什么不选React？
- JSX语法对初学者不够直观
- 需要额外学习Redux等状态管理
- Vue 3的模板语法更接近HTML

### 为什么不选Svelte？
- 生态相对较小
- 第三方库和组件库较少
- AI训练数据相对较少

## 后果

### 积极影响
1. **开发效率高** - Vue 3的`<script setup>`语法简洁，减少样板代码
2. **中文资源丰富** - Vue生态在国内非常成熟，遇到问题容易找到解决方案
3. **渐进式采用** - 可以从简单场景开始，逐步引入复杂功能
4. **TypeScript集成好** - Vue 3原生支持TypeScript
5. **AI辅助友好** - Vue 3有大量开源项目和文档，AI训练数据充足

### 潜在风险
1. **生态相对React较小** - 某些小众需求可能需要自己实现
2. **大型应用架构经验较少** - 需要自己设计模块划分和状态管理

### 缓解措施
- 遵循Vue官方风格指南
- 使用Pinia进行集中式状态管理
- 参考优秀开源项目的架构设计

## 合规说明

本决策符合MIPYAO公司的以下原则：
- ✅ **AI-first战略** - Vue 3有大量训练数据，AI辅助开发效果好
- ✅ **低成本** - Vue 3开源免费，生态成熟
- ✅ **高效率** - 简洁语法，快速开发
- ✅ **可扩展** - 支持大型应用开发
