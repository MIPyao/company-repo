## ADR模板

每个ADR应包含以下部分：
- 状态（草稿/已采纳/已弃用/已替代）
- 上下文
- 决策
- 后果
- 合规说明

## 使用指南

新ADR使用递增编号，参考模板创建，并提交PR供团队review。
